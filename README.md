# attendance-app
千葉工業大学硬式野球部の平日練習期間の自主練習における出欠の確認のためにこのプロジェクトを使用する

以下の手順での運用をする

1、このリポジトリをgithub pagesで共有をかける<br>
2、茜浜野球場で活動を開始する際にこのアプリを起動させる<br>
ーーー初期登録ーーー<br>
3、氏名登録<br>
4、顔登録<br>
ーーー通常運用ーーー<br>
5、練習区分の登録<br>
6、球数入力（任意）<br>
7、確認ボタンを押す<br>
8、位置情報の精査<br>
9、顔認証<br>
